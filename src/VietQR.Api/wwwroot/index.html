Sử dụng C# (.NET SDK) trong Controller / Service

Tích hợp chỉ với 3 bước đơn giản thông qua cơ chế Dependency Injection và Fluent API của VietQR.Core

Bước 1: Đăng ký DI

Gọi builder.Services.AddVietQrDeeplink() trong file Program.cs.

Bước 2: Tạo mã VietQR

Khởi tạo đối tượng new VietQr() và cấu hình số tài khoản, số tiền, nội dung.

Bước 3: Lấy link Deeplink

Gọi extension method qr.ToDeeplinkUrlAsync(...) và trả về URL cho ứng dụng.

CheckoutController.cs 
// 1. Đăng ký dịch vụ trong Program.cs:
builder.Services.AddVietQrDeeplink();

// 2. Tiêm IVietQrDeeplinkClient vào Controller hoặc Service:
using VietQR.Core;
using VietQR.Deeplink.Client;

public class CheckoutController : ControllerBase
{
    private readonly IVietQrDeeplinkClient _deeplinkClient;

    public CheckoutController(IVietQrDeeplinkClient deeplinkClient)
    {
        _deeplinkClient = deeplinkClient;
    }

    [HttpPost("create-payment")]
    public async Task<IActionResult> CreatePayment()
    {
        // Tạo mã VietQR chuẩn NAPAS247 bằng VietQR.Core (NuGet)
        var qr = new VietQr()
            .SetBeneficiaryOrganization("970418", "1241678900", VietQrServiceType.Account)
            .SetTransactionAmount("50000")
            .SetAdditionalData(purpose: "cam on ban");

        // Tạo link Deeplink mở ứng dụng MBBank (hoặc OCB, BIDV, TPB, MOMO, ZALOPAY...)
        var intent = await qr.ToDeeplinkUrlAsync(_deeplinkClient, "MB");
        if (intent is null) return BadRequest("Không tạo được liên kết điều hướng.");

        return Ok(new { url = intent.Url, expiresIn = intent.ExpiresInSeconds });
    }
}

API Lấy danh sách ứng dụng & kiểm tra Autofill

Endpoint lấy toàn bộ danh mục 44+ ứng dụng ngân hàng / ví điện tử được hỗ trợ, kèm mã appCode, logo, và cờ supportsAutofill. Dùng để render dropdown chọn ngân hàng hoặc lọc các app tự điền STK.

GET /api/v1/vietqr-core/deeplink/apps
Không yêu cầu tham số

Gọi bằng cURL:

curl -X GET "https://vietqr.hoangtuan.net/api/v1/vietqr-core/deeplink/apps"
Trường dữ liệu Kiểu Mô tả
appCode string Mã định danh app ngân hàng/ví (VD: MB, BIDV, OCB...).
bin string? Mã BIN 6 chữ số chuẩn NAPAS (null đối với ví điện tử như VNPAY, ShopeePay).
shortName string Tên viết tắt của ngân hàng/ví (VD: MBBank, BIDV, Vietcombank).
appName string Tên hiển thị đầy đủ của ứng dụng trên App Store / CH Play.
logo string Đường dẫn logo ứng dụng (PNG).
supportsAutofill boolean true: Deeplink mở app + Tự động điền STK, Số tiền và Nội dung; false: Deeplink mở trực tiếp app ngân hàng trên điện thoại (dẫn vào app hoặc màn hình quét QR).
supportsIos boolean true nếu ứng dụng hỗ trợ điều hướng trên thiết bị iOS (iPhone/iPad).
supportsAndroid boolean true nếu ứng dụng hỗ trợ điều hướng trên thiết bị Android.

API Khởi tạo phiên điều hướng Deeplink

Áp dụng cho mọi ứng dụng không dùng .NET (Node.js, Python, PHP, Java, Go, Ruby...) hoặc các frontend SPA/Mobile gọi trực tiếp API.

POST /api/v1/vietqr-core/deeplink/intents
Content-Type: application/json
Trường dữ liệu Kiểu Bắt buộc Mô tả
appCode string Có Mã app ngân hàng ưu tiên mở: MB, BIDV, OCB, TPB, CAKE, MOMO, ZALOPAY, VCB... (Lấy từ API /deeplink/apps ở trên).
qrCode string Có Chuỗi dữ liệu VietQR EMVCo đầy đủ với mã kiểm tra CRC16 hợp lệ (bắt đầu bằng 000201...).
Định dạng dữ liệu trả về (Response Payload) 
{
  "code": "00",
  "desc": "Thành công",
  "data": {
    "url": "https://vietqr.hoangtuan.net/p/8f1e2d3c",
    "expiresInSeconds": 300
  }
}

async function createDeeplink(appCode, emvQrCode) {
  const res = await fetch('/api/v1/vietqr-core/deeplink/intents', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ appCode, qrCode: emvQrCode })
  });

  const json = await res.json();
  if (json.code === '00') {
    // Điều hướng người dùng tới liên kết mở app
    window.location.href = json.data.url;
  }
}

Danh mục API Endpoints

              

                Các endpoint chuẩn RESTful phục vụ sinh mã, kết xuất đồ họa và phân giải Deeplink tại đường dẫn gốc /api/v1/vietqr-core.
              


              

                

                  
                    

                      Method
                      Endpoint
                      Chức năng
                      Kiểu trả về
                    

                  
                  
                    

                      GET
                      /generate
                      Sinh chuỗi EMVCo và chuỗi Base64 Data URL
                      JSON
                    

                    

                      POST
                      /generate
                      Như GET, truyền qua request body (hỗ trợ logo tùy biến)
                      JSON
                    

                    

                      GET
                      /image
                      Trả về trực tiếp luồng binary hình ảnh (PNG, WebP, SVG)
